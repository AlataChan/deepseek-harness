# 智能体角色头像实施计划

[English](2026-10-14-assistant-character-avatars.md) | 中文

**目标：** 为智能体与常驻团队提供已确认的默认「海边小伙伴」及可选「软萌机器人」头像。

**架构：** 扩展 `client-ui-assistants` 共用的 `EntityAvatar` 与 `AvatarPicker`。八个装饰性 SVG 角色随 Client 打包，选择保存在现有可选头像字符串中。未设置头像时使用海边小鲸鱼；历史空字符串保留姓名缩写，历史图标仍可显示。不修改 Host 操作、会话事件、依赖或应用标志。

**技术栈：** React、TypeScript、CSS Modules、现有主题变量、Vitest 与浏览器验证。

## 已确认设计

海边小伙伴包含叶鳍小鲸鱼、小海豹、水母和寄居蟹；软萌机器人包含四个天线、耳朵和表情不同的圆润机器人。两套采用有表情的面孔、圆润轮廓和克制的浅色填充。选择器分别展示两组名称，标注海边系列为默认，并保留独立的姓名缩写选项。不采用已否定的几何小精灵方向。

## 任务一：选择与兼容

在 `packages/experimental/client-ui-assistants/tests/character-avatar.client.spec.tsx` 中先编写默认显示、八个角色选择、历史图标和姓名缩写、键盘选择、禁用状态及独立表单单选组的失败测试。运行该文件，确认缺少角色实现时测试失败。增加内部角色渲染组件，扩展 `EntityAvatar.tsx`、对应 CSS 与本地化字典。新表单默认选择海边系列，不重写已有目录记录。

## 任务二：挂载表单与持久化

更新智能体创建、详情编辑、团队创建和团队编辑，区分未设置头像与明确保存的姓名缩写。更新现有头像测试，覆盖角色选择及保存失败后保留原选择。运行两组头像测试及挂载工作流测试，沿用已有持久化目录和 Remote 操作。

## 任务三：视觉与发布验证

使用实际组件和主题 CSS，检查两套角色在浅色、深色主题下的 26px 与 40px 显示效果，并检查键盘焦点和窄表单布局。更新包 README 双语版本，执行 Client 编译、本地化、包检查和针对性测试，构建 Client。增加两套头像的桌面打包断言，重建 DMG 并执行安装版生命周期验证。日志与视觉证据保存到 `.plans/persistent-assistants/character-avatars/`。
