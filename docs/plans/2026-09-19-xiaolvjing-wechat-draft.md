## 正文（可直接粘贴）

写文书、整案例、问表格：小绿鲸开源给公益同行

小绿鲸开源了。

它是元公益做给公益人的 AI 工作台：写项目书、整理案例、问自己的表格和文档，都在同一个窗口里完成。

不是又一个聊天网页。打开就是工作台。先选工作文件夹，再提问。新用户只需填 API Key，安装器会处理运行时。

源码在 Gitee：https://gitee.com/jasonchan0754/octopus_DSH

它站在开源的 DeepSeek Harness 之上，由元公益做成面向机构日常的桌面。不是 DeepSeek 官方桌面，也不替代你们已有的办公软件。

### 公益人每天在忙什么

立项书、结项材料、资助信。

访谈笔记要脱敏，再做成能存档的案例卡。

活动复盘要写成能发的推文，又不能编成效数字。

手里常有 Excel、年报 PDF、微信长文，却没有数据库管理员。

小绿鲸按这三条流水线来：文书、案例、传播。编制先于对话。点「文书组」「案例组」「传播部」，是把活派给还在的队，不是每来一个话题再组一次人。

默认助理仍是通用助手。需要公益口径时，新会话里点「公益项目助手」。

### 三个按钮，对应三种材料

**问数。** 先有表，再提问。用示例走一遍，或下载模板填好再上传 `.xlsx` / `.csv`。一份文件就是一个数据源。选中之后，页上只有一个「开始提问」。不用手写 SQLite 路径。

**问知识。** 把年报、方案、制度放进知识库，之后按词检索。也可以只看这一份文档、不入库。表格请走问数，不必为 Excel 再装一套重工具。

**机构小队。** 文书组管资料、起草、核数字、审口径。案例组管笔记整理、脱敏、案例卡、归档。传播部管素材边界、提纲、说人话初稿、发布前审校。主控分派和收口，不替你编预算、人数、成效。

材料直接贴进对话。不必按工种分别指定文件路径。

协作过程可以在右侧舱里看：谁在做、任务怎么接、消息怎么走。需要留图时，再生成一张总结图。

### 窗口里还能看见什么

中文界面。侧栏品牌是「小绿鲸」，旁边是绿叶鲸鱼标。

空白首页是浅海沙滩，开聊即淡出，不抢输入。

左侧可以看工作文件夹里的文件。

装好后带微信公众号提取：把一篇推文收成可引用的正文，并有本地限流，避免刷爆平台。

社区插件市场是可选设置，不会在开机时替你乱装东西。

### 怎么开源、怎么安装

代码公开在上面的 Gitee 仓库。欢迎看、改、提问题。我们不向上游 DeepSeek 开产品向 PR；这是元公益维护的公益桌面发行。

当前分发以 macOS 安装包为主，文件名是 `octopus_DSH.dmg`。那是工程名，窗口里仍叫小绿鲸。

微信或浏览器传来的安装包，macOS 常会误报「已损坏」。不是文件坏了。把应用拖进「应用程序」后，打开「终端」，粘贴这一行回车：

```
xattr -cr /Applications/octopus_DSH.app
```

也可以双击安装盘里的「安装并打开」。

装好后：设置 → 模型，填入 API Key。新建会话需要公益口径时，选「公益项目助手」。

### 我们守住的几条

不编造预算、人数、成效。缺材料就写进缺失项清单。

案例对外之前先脱敏：去姓名、手机、身份证，地址不超过区县。

传播稿发布前审校敏感信息和过度承诺；小绿鲸不代发微信、不代提交资方。

你的表格和文档留在自己的电脑和工作文件夹里。API Key 由你配置。

### 写给同行

如果你们正在为结项周报熬夜，为访谈笔记找不到结构发愁，为「表在手里、问题问不出去」卡住，把小绿鲸装上试一天。

先用问数里的示例表走通一遍。再丢一份自己的脱敏材料给案例组。看它能不能把「整理—脱敏—成卡—入库」走完，而不向你要四份路径。

源码、讨论、安装包，都从这一处开始：

https://gitee.com/jasonchan0754/octopus_DSH

小绿鲸是工作台，不是代写机器。材料仍是你们的，判断仍是你们的。它负责把重复的整理、核对、成稿，从夜里挪回白天。
