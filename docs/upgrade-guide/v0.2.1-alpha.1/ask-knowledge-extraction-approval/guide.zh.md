# 问知识提取预算批准

[English](guide.md) | 中文

## 变更

上传知识库文档后，系统先保留原件并为完整转换文本建立检索索引，不再自动启动付费的词条提取。现有原始文本和手写词条仍可检索；旧版本已丢弃的原件字节无法通过迁移恢复。

知识库文档列表显示原件留存、转换限制、提取状态和整份文档的预算。重试会生成新的估算。对于计费或执行结果不确定的中断请求，系统不会自动重复调用。官方会话附件现在通过授权转换和有界读取访问超过 32,000 字符的内容；原件仍归官方附件存储管理，不会自动成为知识库文档。转换受 `maxIngestBytes` 限制（默认 20 MiB），拒绝转换不会删除原件。工具显示游标和诊断；原文读取前必须先在同一轮记录 Wiki 工具结果。旧转换缓存会自动重建。

`extractionContextChars` 现在统计完整序列化 Wiki 上下文，包括页面路径和 JSON 封装，不再只统计页面正文。既有配置值仍有效，但可容纳的正文可能减少。新计划按完整请求计算保守额度，不会自动启动付费处理。仅在确实需要更大上下文时提高该设置，并确认新的估算额度。

## 迁移

1. 安装新版桌面应用，打开现有知识库并保留其目录。启动时会登记旧版原始文本，不会重写手写词条。
2. 在设置中展开知识库，检查各文档的转换状态和预算估算。如果需要保留旧文档的原件，而列表显示原件不可用，请重新上传。
3. 准备启动模型提取时，再选择批准预算。模型路由仍由知识库的 `.octopus-kb/config.toml` 管理，不会修改应用的全局模型设置。
4. 确认未批准的上传文档可被检索且未发起模型请求；批准一份文档后，检查生成的词条及记录的用量。重启应用后，已完成的分段应继续保持完成状态。结果不确定时，请先阅读额度提醒，再选择单独的付费重放确认；普通继续按钮不能重复这些调用。对于明确失败的任务，可通过重试获取新的估算。
