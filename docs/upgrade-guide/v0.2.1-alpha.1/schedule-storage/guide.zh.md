# 定时任务存储兼容性

[English](guide.md) | 中文

## 变更

定时任务领域通过 `compatibleVersions: [1]` 读取已发布版本 1，下一次修改写入版本 2。旧版精确版本读取器拒绝版本 2。打开和关闭旧 JSON 文件不会重写文件。会话日志代际、历史 `schedule/change` 事件和全局 SQLite schema 保持不变。

读取规范化将 `sessionId` 转为会话目标，将 `inactive` 转为结束状态。历史回执保留，缺失的回执目标仅从已有或保留目标补充。当前记录还保存修订、参与会话标识和待投递保留。工具及远程 API 的迁移见[任务管理](../schedule-tasks/guide.zh.md)。

待投递和保留目标会话标识在新建会话前写入同一任务行。恢复时采用该标识。保留、会话入队和任务回执仍分别写入，因此崩溃后可能重复投递消息。

## 迁移

1. 在此版本首次编辑或投递前备份定时任务存储。如需回退，请保留配套旧运行时；不要用旧版打开修改后的版本 2 存储。
2. 确认已有任务显示会话目标，结束任务保留历史。运行时使用存储期间，不要让外部程序写入文件。
3. 执行一次计划中的任务编辑，重启后确认编辑和历史仍存在。验证投递恢复时，确认复用保留目标；不要据此认为消息不会重复。
4. 如需回退，先停止新版运行时，恢复修改前的备份，再启动旧版运行时。
