# 输入框接纳与本地回显

[English](guide.md) | 中文

## 变更

本地提交注册在 Host 接纳前不公开回显。输入框在 sending 阶段保留只读文档，仅在接纳后清空。调用 beginSubmission 后立即绘制回显的集成需要等待提示请求被接纳。

在手机和平板上，选择工作区后，新启用的输入框不会自动获取焦点，包括工作区接纳在弹窗关闭后才启用输入框的情况。若文本输入控件在弹窗打开前不可编辑，关闭弹窗不会自动将焦点移回该控件；原先可编辑的控件和普通按钮仍会恢复焦点。发送被拒绝时保留草稿和编辑焦点；接纳后清空草稿，并将焦点移到输入卡片。

## 迁移

1. 在自定义输入控件中处理 `sending` 阶段。
2. 保留完整草稿和附件 ID，直到 `prompt()` 返回接纳结果；拒绝后继续编辑原文档。
3. 从 `snapshot.pendingSubmissions` 读取已接纳的回显，确认首次发送被拒绝后会话仍为空白。
