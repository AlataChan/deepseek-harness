# 读取平台内容

[English](agent-reach.md) | 中文

Octopus 内置轻量 Agent-Reach 插件。在普通会话或团队会话中直接使用，不需要创建新的媒体智能体。

1. 要求查看 V2EX 主题、Bilibili 视频或 YouTube 字幕信息。助手可以先查询支持的动作。
2. 提示缺少依赖时，请助手准备环境。在安装确认中核对版本、目录和许可证。拒绝不会影响 Octopus 继续使用。
3. 安装成功后，重新发起需要的查询。后续读取复用已安装环境。

包括完全访问模式在内，安装都要交互确认。安装使用独立运行环境和固定依赖，不替换系统 Python、Node，也不改变登录信息。打开 Octopus 本身不会下载这些依赖。安装成功后，平台仍可能限制访问或要求登录。

## 浏览器会话与登录

Bilibili 字幕默认禁止，因为上游动作可能导入浏览器会话并写入凭据。管理员必须在插件配置中明确允许那个动作和引擎。安装依赖不授予此许可。需要启动浏览器的引擎在资源归属验证完成前不可用。不要把密码或 Cookie 粘贴进会话。

公开摘要、已加载评论和字幕轨列表可能不完整。请查看结果的完整性标记和来源链接。遇到登录限制或频率限制时直接报告，不自动切换账号。

## 关闭与清理

在插件页面禁用此插件，刷新内置插件不会覆盖你的选择。管理员也可以设置 `enableSetupTool: false`，保留读取工具并隐藏安装工具。

禁用会停止当前工作，但保留运行环境和账号数据。要清理已下载运行环境，先停止插件，只删除 `<DSH_HOME>/runtimes/agent-reach`。这不会删除 `~/.agent-reach` 中的上游账号状态。异常中断留下的 `.setup.lock` 需要先检查，安装仍在运行时不能删除。

手动部署可以通过 DSH 正常插件命令安装单独打包的插件。外部运行环境需要管理员指定绝对路径并核实，不要安装同名但无关的 PyPI 包。[包文档](../../../packages/experimental/agent-reach/README.zh.md)说明配置、进程限制和运行记录。
