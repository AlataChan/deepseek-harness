## 这个工具包里有什么

本工具包是《环保组织AI数字化能力建设指南》的配套交付物，按使用场景分了五个文件夹。手册每一章讲到具体操作时，都会引用这里对应的模板。

| 文件夹 | 对应手册章节 | 内容 |
|---|---|---|
| 01-技能模板库 | 第二章、第五章 | 六大技能模板，复制后改成你机构的版本即可用 |
| 02-知识库工具 | 第三章、第七章 | 建知识库用的三张表 |
| 03-Agent配置 | 第四章、第六章 | 组装项目助理的立项书、检查清单、同事使用说明 |
| 04-运营跟踪 | 第六章 | 发布后90天跟踪用的表格和话术 |
| 05-真实案例集 | 第八章 | 6家机构完整案例 |

## 三种文件类型怎么用

- **.md 文件**（技能模板、话术）：是纯文本。用法是——打开文件，全选复制，粘贴到 AI 工具的技能配置区（或直接放进对话里），然后把里面的示例内容换成你机构的真实信息。
- **.xlsx 文件**（各种表）：用 Excel 或 WPS 打开，直接填写。也可以上传到腾讯文档/钉钉表格改成在线协作版。
- **.docx 文件**（需求单、使用说明、案例集）：用 Word 或 WPS 打开，填空、改写均可。

## 建议的使用顺序

1. 先读手册第四章，填《项目助理需求单》（03-Agent配置），想清楚做什么。
2. 按手册第二章，从 01-技能模板库 挑一个最痛的场景，复制模板改成你的技能。
3. 按手册第三章，用 02-知识库工具 的三张表整理资料、分级入库；知识库建好后，用 01-技能模板库/知识库管理 里的 octopus-kb 技能包帮你养护。
4. 按手册第四章组装助理，用 03 里的检查清单核对。
5. 发布后，用 04 的表格做运营跟踪。

## 注意事项

- 所有模板里带【】的部分是提示语，替换成你自己的内容后删除括号。
- 涉及受益人、捐赠人、志愿者个人信息的资料，先按手册第七章做脱敏，再喂给AI。
- AI 生成的所有事实、数字、引用，发布前必须人工核对。
