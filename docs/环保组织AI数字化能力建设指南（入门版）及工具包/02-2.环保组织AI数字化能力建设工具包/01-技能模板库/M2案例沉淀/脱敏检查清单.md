# 案例脱敏检查清单（M2 案例沉淀 · 入库前必查）

> 用法：案例入库或对外发布前，逐项打勾。任何一项不达标，先整改再入库。
>
> 原则：对内可留真实姓名（标注「内部存档」），对外必须脱敏。宁可多防一层，不要事后后悔。

## 一、人的信息

- [ ] 当事人姓名已化名（如小A、化名），或标注为「内部存档」
- [ ] 手机号已全部删除（不是打码——打码可被技术还原）
- [ ] 身份证号、住址、微信号已全部删除
- [ ] 当事人亲属信息已一并脱敏
- [ ] 志愿者、工作人员的姓名已按同样标准处理

## 二、地点信息

- [ ] 学校、村庄等具体地点已模糊到县/区一级
- [ ] 其他独特地标、门牌号已删除或模糊化

## 三、内容信息

- [ ] 案例只包含素材里有的事实，无脑补情节
- [ ] 直接引语均来自素材原文
- [ ] 未公开的项目数据、财务信息未混入案例正文
- [ ] 涉及合作方、资助方的非公开信息已删除

## 四、发布前最后检查

- [ ] 自己通读一遍：「如果我写的那个人看到这篇，能认出自己吗？」认不出，才算过关
- [ ] 对外版本与内部存档版本已分开存放
- [ ] 发布渠道已确认有授权（当事人或机构负责人同意）

## 常见错误

| 错误做法 | 正确做法 |
|---|---|
| 给身份证打码后发布 | 直接删除号码 |
| 用真实姓氏+化名（如“张某”） | 完全化名（如“小A”） |
| 同一个案例内外混用一份 | 分「内部存档」「对外脱敏」两个版本 |
| 为了故事生动补写对话 | 只用素材原文，没有就不用引语 |
