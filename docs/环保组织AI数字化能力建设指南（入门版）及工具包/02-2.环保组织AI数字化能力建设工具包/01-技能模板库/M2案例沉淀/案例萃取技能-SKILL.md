# 案例萃取技能（案例沉淀 · M2）

把零散的访谈记录、活动流水账，整理成结构统一、可检索、可复用的案例卡片。这是机构知识库的核心加工技能。

## 什么时候用

- 用户提供了原始素材：访谈录音转写、活动记录、志愿者观察笔记、服务对象反馈。
- 用户想把素材整理成**结构化案例**，存入机构案例库。
- 触发关键词：整理案例、萃取案例、案例卡片、入库、服务故事。

不要用于：写对外传播的推文（用公众号推文技能）、生成完整项目总结（用结项报告技能）。

## 工作流程

1. 通读原始素材，识别核心事实：谁、在哪、发生了什么、结果如何。
2. 按下方案例卡片结构逐项填充。
3. 脱敏检查：姓名化名、删除联系方式、模糊定位（见避坑要点）。
4. 打标签：按场馆/议题/服务类型/人群等维度。
5. 输出后请用户确认，再入库。

## 需要的输入

- 原始素材（访谈记录、活动记录等）。
- 案例归属：哪个项目、哪个场馆/地点、大致时间。
- 标签体系（若机构已有）。

## 输出契约

每张案例卡片包含以下字段，顺序固定：

1. **案例标题**（一句话，说清主角和事）
2. **基本信息**：项目名、场馆/地点、时间、记录人
3. **背景**：当事人情况、活动背景（≤100字）
4. **过程**：发生了什么，关键细节
5. **变化与结果**：当事人的变化、可观察的结果
6. **标签**：按机构标签体系填写
7. **脱敏状态**：已脱敏 / 内部存档（未脱敏）
8. **待核实项**：素材里存疑或缺失的信息

单张卡片 300–600 字。

## 避坑要点（质量约束）

- 当事人姓名一律化名（如小A、化名）；手机号、证件号、住址删除；学校/村庄模糊到县一级。
- 只写素材里有的事实，不脑补当事人的心理活动和对话。
- 直接引语必须来自素材原文，不编造金句。
- 对内存档可保留真实姓名（标注「内部存档」），对外发布必须脱敏——两者分库存放。
- 案例不是表扬稿：变化不明显的就如实记录，不强行拔高。

## 卡片模板（替换括号内容）

```markdown
# 案例：【一句话标题】

- 项目：【项目名】
- 场馆/地点：【名称】
- 时间：【年月】
- 记录人：【化名/代号】
- 脱敏状态：【已脱敏｜内部存档】

## 背景
【当事人情况、活动背景】

## 过程
【发生了什么】

## 变化与结果
【可观察的变化】

## 标签
【议题/服务类型/人群】

## 待核实项
- 【存疑或缺失的信息】
```
