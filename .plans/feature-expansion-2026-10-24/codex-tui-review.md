# TUI independent review — round 1

Verdict: changes required. Codex independently ran `pnpm vitest run packages/tui/tui/tests/`: 11 files / 36 tests passed. These tests do not establish the approved acceptance matrix. No release or stable-promotion acceptance is granted.

1. **P1 — Installed qualification and promotion are unsupported.** `tests/official-profile.spec.ts` imports workspace source, anchors resolution at checkout `apps/cli/package.json`, and only composes metadata. `assembled-profile.spec.ts` hand-mounts plugins with a fake Agent factory and streams. Neither installs tarballs outside checkout, launches the actual CLI, or exercises real multi-turn Agent behavior. The implementation report incorrectly claims T5/T6 installed acceptance and complete criteria. Supply actual keyless installed experimental and stable CLI/PTY evidence, including real persistence, model and native/PTC executor behavior; correct the report and defer stable registration until prerequisites pass.

2. **P1 — Terminal input can emit untrusted controls and memory is unbounded.** `input.ts` only recognizes whole-chunk escape delimiters, so splitting bracketed-paste start/end across chunks bypasses paste handling. Paste bytes accumulate without a limit until termination, history grows indefinitely, and renderer writes `state.draft` directly. Pasted terminal controls can consequently execute during redraw. `sanitizeUntrustedOutput` also leaves C0/C1 controls such as CR, BS and 8-bit CSI. Implement a bounded incremental parser, safe draft rendering and complete control filtering, with split-at-every-byte, unterminated paste, oversized chunk and real emulator negative tests.

3. **P1 — Rendering does not implement streaming or multiline cursor placement.** `session.ts` accumulates text deltas but only appends them on end/idle; repaint never receives the accumulator. `render.ts` always positions the cursor on the last terminal row with the total width of the prefix, ignoring newlines and wrapped draft rows. No-interaction layout writes rows+1 lines, scrolling the frame. Validate actual screen/cursor cells at narrow widths, resize and multiline input, and show incremental output before commit without duplicate persisted-message rendering.

4. **P1 — Pending interactions can be lost or answered incompletely.** `interaction.ts` overwrites `activeApproval` / `activeQuestion` on concurrent requests, leaving earlier promises unresolved. Questions answer only `questions[0]`, ignoring the remaining batch and multiSelect. Abort listeners are never removed after normal settlement; approval input does not revalidate the active Agent/request. Implement one owned serialized interaction queue with cancellation and request identity checks, full batch/multi-select answers and disposal tests. Exercise real executor side effects on both native and PTC rejection, expiry, switching and disconnect paths; current four tests do not do so.

5. **P1 — Agent lifetime is not awaited or admission-serialized.** `index.ts` disposer fires `void session.dispose()` and returns before cancel/idle/release; initialization can publish a handle after plugin teardown. Input starts before initialization, async session switches can overlap, and running-turn submissions immediately call followup despite the approved draft-until-idle behavior. Register owned cleanup before terminal changes, close admission, settle pending work, await bounded cancellation/persistence/handle disposal, and contain callbacks after teardown. Add delayed-create/switch/dispose controls.

6. **P2 — Terminal restoration ownership is incomplete.** `index.ts` enters alternate screen before registering the optional restore hook; `restoreTerminalNow` unconditionally sets raw false instead of restoring the prior state and writes exit sequences irrespective of owned modes. Input/render continue during fatal restore until eventual asynchronous cleanup. Register required restore ownership first, track original raw state and modes actually entered, synchronously stop admission/render on restoration and cover partial initialization/output loss. The HUP suite recreates callbacks in the test; it does not launch real nohup or test the actual launcher's signal wiring.

7. **P2 — Session/model behavior is incomplete.** `/model` accepts arbitrary provider/model strings without catalog selection or reasoning effort; no actual request proves the chosen route. Session replay scans the entire log, renders both prompt echo and persisted user events, leaves stream/sequence state across new sessions, and reports generic success for all tool results instead of using persisted presenter metadata. Implement bounded replay, single authoritative transcript rendering, per-session state reset and actual provider/model/effort selection evidence.

8. **P2 — Type and documentation conformance remain open.** New production code adds `as unknown as`, injected service reads are undeclared (`ctx.tools`), user-visible Chinese/English literals bypass dictionaries, schema numeric bounds are not validated, and secret redaction is only top-level. Run scoped source-and-test typecheck/lint and relevant publication/intake/docs gates; recursively redact bounded summaries, use typed event data and document actual limitations. Passing tests alone cannot justify these claims.

AGY owns remediation in this same worktree. Preserve all preexisting expansion and unrelated changes. This report records observed code/test gaps; platform or full-repository acceptance remains unverified.
