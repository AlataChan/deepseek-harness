# TUI independent review — round 2

Verdict: changes required. Codex reran `pnpm vitest run packages/tui/tui/tests/`: 12 files / 58 tests passed. Several repairs improve the implementation, but the report's complete/stable-ready claim remains unsupported.

1. **P1 — Artifact acceptance is still missing.** `installed-qualification.spec.ts` sets `cliBin = join(process.cwd(), 'apps/cli/lib/bin.js')`. The extracted tarballs are inspected, never installed or executed. Product dependencies still resolve from checkout. Its “multi-turn” case sends one prompt; model effort case exits immediately after the UI echo without a model request; no real nested PTC approval executor is exercised. Replace this with an explicit independent installed closure outside checkout, separate experimental/stable acceptance, two actual turns, durable restart/resume and real native/PTC allow/reject/error side effects. Fail when the artifact is absent or checkout resolution is attempted. Correct every contrary claim in the report.

2. **P1 — Disposal still does not join startup or bound cleanup.** SessionAdapter.dispose marks disposed and calls quiesceAndRelease, but an in-flight agents.create/resume can finish later and then dispose its new handle after the plugin teardown returned. whenIdle/dispose have no deadlines; errors are swallowed. index.ts restores the terminal only AFTER awaiting session.dispose, so a stuck disposer prevents normal-exit restoration. Track and join the active transition, close admission synchronously, restore before fallible async cleanup, bound waits, report independent cleanup failures, and ensure late acquisition is fully settled before successful teardown. Test deliberately deferred factories and stuck/throwing handle cleanup.

3. **P2 — Width/cursor acceptance still has concrete errors.** render.ts clamps actual terminal dimensions up to 20x10, writes wider/taller frames into smaller real terminals, truncates header with UTF-16 slice, and displays the last six draft lines while calculating cursor offset from the untrimmed beginning. Wide graphemes at wrap boundaries also cannot be positioned by total-width division. Use actual dimensions, grapheme-width clipping and a cursor-visible input viewport derived from the same layout; assert cells/cursor using xterm for narrow, overflowing, mid-draft, exact-wrap and mixed CJK cases.

4. **P2 — Model selection remains unvalidated and pending input can be lost.** handleCommand still accepts arbitrary provider/model/effort and setModel immediately publishes it; catalog listing alone does not validate the choice. pendingPrompt is a single overwritten string, so two submissions during a running turn silently discard the first. Preserve editable pending input or reject a second admission visibly; verify actual next model request route/effort, catalog errors and persistence behavior. Localize remaining hardcoded product strings.

5. **P2 — Secret redaction and test ownership remain incomplete.** redactSecrets checks object-valued fields before sensitive key names, so `{password:{value:'secret'}}` leaks. Depth overflow returns the original unredacted subtree. Make sensitive-key masking unconditional and truncate deep/large data without returning originals. The PTY runner inherits real HOME/env, timeout/error kills without awaiting child exit, and deletes temp data while script/poll work may still run. Use private HOME/credential state, scrub real secrets and join exact owned child/script/poll cleanup. Replace any type escapes with typed current APIs and run a check including tests. Record exact commands/logs rather than saying all hygiene passes.

Unclosed round-1 acceptance requirements remain required. A passing helper suite or tarball listing is not installed runtime acceptance. No commit, merge or release is authorized by this review.
