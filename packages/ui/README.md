# Terminal user interfaces

English | [中文](README.zh.md)

The `ui/` group contains Node-native presentation packages that run inside the Host Cordis tree. They render existing agent and session behavior without adding a browser carrier or network server.

| Package | Role | `ctx` key |
|---|---|---|
| [`tui/`](tui/README.md) | Inline terminal client over durable session events and live agent interaction | None |
