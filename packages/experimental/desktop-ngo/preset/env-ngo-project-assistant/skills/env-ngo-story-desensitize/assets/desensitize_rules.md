# 服务故事脱敏规则

> 适用范围：需公开发布的服务故事、受益人叙事、访谈记录、案例文本。
> 下表「原始示例」只用占位符，不写姓名、证件号、电话或门牌。

## 脱敏对照表

| 信息类型 | 原始示例 | 脱敏处理 | 输出示例 |
|----------|----------|----------|----------|
| **真实姓名** | `[姓名]` | 替换为字母代号，同一人全文统一 | 受益人 A |
| **手机号** | `[11位手机号]` | 直接删除 | [已删除] |
| **身份证号** | `[18位证件号]` | 直接删除 | [已删除] |
| **银行卡号** | `[银行卡号]` | 直接删除 | [已删除] |
| **精确金额** | `[精确到个位的金额]` | 量级范围 | 约 4 万元 |
| **详细地址** | `[精确到街道门牌的地址]` | 模糊到区县 | 某市某区某社区 |
| **机构全称** | `[机构全称]` | 机构简称或代号 | <机构简称> |
| **照片中人脸** | 清晰正面照描述 | 标注需打码 | [建议对人脸打码后发布] |
| **未成年人信息** | `[未成年人姓名]，12 岁，[学校全称]六年级` | 代号 + 删除学校 | 学生 B，12 岁 |
| **疾病/残障信息** | `[姓名]确诊某病` | 模糊描述 | 受益人 A 因健康原因 |

## 处理原则

1. **同一人统一代号**：首次出现分配 A/B/C，后续全文一致。
2. **删除优先于遮盖**：手机号、证件号不做部分遮盖（例如保留首尾数字），直接删除。
3. **金额用量级**：千元级→「约 X 千元」，万元级→「约 X 万元」，百万级→「约 X 百万元」。
4. **不改变事实**：脱敏是保护隐私，不是美化或修改事件经过。
5. **存疑则标注**：不确定是否需脱敏的内容，标注 `[请确认是否需脱敏]` 交由用户决定。
6. **未成年人从严**：涉及未成年人的信息，学校名称、班级、家庭住址一律删除。
