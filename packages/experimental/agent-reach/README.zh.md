# @deepseek-ai/dsh-experimental-agent-reach

[English](README.md) | 中文

## 概述

Octopus 桌面默认启用这个轻量 Host/Client 插件，为现有会话提供平台能力发现、本地状态、限量只读查询和独立的依赖安装工具。启动时不监听新端口，也不下载依赖。此插件不会向桌面安装包加入 Python 运行环境、Agent-Reach 环境、浏览器或媒体程序。

## 使用

直接要求读取平台内容。缺少依赖时，`reach_setup` 通过 DSH 现有审批服务展示固定安装计划。每次安装都需要新的交互确认，包括完全访问模式；禁止审批、拒绝、没有应答方或取消时均不下载。`planOnly` 只预览，不修改环境。安装后重新发起查询，不自动重放旧请求。

[用户指南](../../../docs/user/guide/agent-reach.zh.md)介绍首次使用和清理。普通会话与团队成员沿用现有工具可见性，不需要专用智能体预设。

<a id="configuration"></a>

## 配置

Cordis 的 `agent-reach` 行接受 `Config` 声明的配置。服务在创建时统一补齐默认值：未提供或为 undefined 的平台配置保留默认值，显式空列表则禁用查询。两份权限列表均会复制，调用方之后修改原数组不会改变运行中的权限。`enabledChannels` 默认包含 Bilibili、YouTube 和 V2EX；实验平台还需要单独许可。`enableSetupTool: false` 隐藏安装工具，保留三个只读工具。`runtimeOverride` 必须是管理员核实过的绝对启动路径，不从环境 PATH 自动查找。

`sessionAccessRoutes` 默认为空列表。每项必须精确到 `channel/action/backend`，不接受通配符和未知路径。Bilibili 字幕需要明确允许浏览器发现、Cookie 导入和原生凭据写入。安装许可不授予会话访问许可。需要启动浏览器的引擎在共享进程归属验证完成前不支持。未知安装方式返回不支持，不调用上游浮动下载器。

输出、并发、查询和安装时限、进程退出宽限均可配置。`maxOutputChars` 限制条目字段、尝试记录和诊断信息中所有可变字符串的总字符数；固定 JSON 键与状态枚举不计入。完整 CLI JSON 另有字节上限。适配器不自动重试查询。

<a id="runtime-ownership"></a>

## 运行环境归属

`dependency-lock.json` 固定 uv、Python 发行包和所有 wheel，包括间接依赖和构建依赖。固定源码归档由固定构建器复现，生成的 wheel 必须与独立验证的摘要一致才能安装。不会仅凭版本号相同就替换为上游发布的 wheel。获取文件后按哈希验证，离线安装 wheel，不重新求解依赖。

运行代际位于 `<DSH_HOME>/runtimes/agent-reach/releases/<lock-id>/generations/`。venv 的绝对路径保持稳定，验证后原子替换归属记录以启用新代际。失败安装只清理自己创建的目录，保留旧记录。每个版本的锁阻止并行安装；异常中断遗留的锁需要管理员检查。记录升级由运行时负责，拒绝未知版本、损坏字段和越界路径。账号状态仍由上游按系统用户保存，同一系统账号下的不同配置可能共享登录信息。

上游私有工具可能优先于 PATH。发现冲突或无法检查的私有工具位置时，在执行引擎之前拒绝，不自动修改用户工具。只使用固定源码，同名 PyPI 项目不能替代。

<a id="model-experience"></a>

## 模型体验

### 平台读取与安装

#### 模型可见内容

能力发现展示动作参数、引擎、副作用和启用状态。结果保留来源链接、访问范围、完整性和有长度限制的尝试记录。未经验证的完整性保持未知，不把摘要、字幕轨列表或部分评论称作完整内容。省略任意原始数据和更新通知，输出中的凭据特征在展示之前脱敏。用户消息或工具参数中的凭据仍可能进入普通会话日志，不应在聊天里索要。

#### Token 消耗

`reach_query` 的结果保留有上限的条目与诊断；安装计划列出固定依赖。卡片的结果元数据不进入模型文本。

#### KV Cache 影响

工具与指导在插件启用期间保持稳定。查询和安装结果追加到当前回合；插件配置变化会改变后续请求前缀。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- **平台支持：** 仅允许已经验证的 macOS Apple Silicon 主机安装和执行运行环境。其他主机仍可发现能力，但不会启动依赖下载或引擎。锁文件中的其他平台配方仍需独立验证。
- **外部访问：** 平台可能要求登录或限制请求。macOS 的进程测试不代表 Windows/Linux 已通过；共享浏览器不属于单次查询拥有的资源。
- **排除的动作：** 不提供发布、私信、账号配置、转录、FFmpeg 安装或通用包管理。
