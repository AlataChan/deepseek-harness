# @deepseek-ai/dsh-experimental-assistant-registry

[English](README.md) | 中文

## 概述

`assistant-registry` 是实验性叠加层包，提供常驻助手档案、已保存团队定义、私密会话绑定、作用域模型路由优先级执行以及角色系统提示词段落注入。

## Stage C 执行与辅助调用记录

轮次从空闲 Agent 开始，独占完整执行区间。取消席位时只移除该席位自己的输入，保留其他输入，中止执行并等待空闲后释放执行权；席位超时采用相同流程。模型请求限制剩余输出 token，实际输入与输出用量计入累计额度；提供方返回用量前，输入计费可能已超过剩余额度。重启后的未确认执行标记为待确认，不自动重跑；已提交回复在重启后只发布一次。轮次准入身份包含接收席位及解析后的执行限制。

自动记忆审核只在专属会话成功结束一轮后运行，使用该轮有界的用户与助手文本。输入建议从 Host 获取最近已完成轮次的上下文，不使用编辑器修订号。辅助调用的模型请求和结果保存为 `assistant/auxiliary` 会话事件，计费用调用 ID 去重；这些事件不创建会话轮次。包含该事件的新日志需要具有 assistant-registry 事件声明的运行时。

输入建议根据同一会话中已记录的上下文为当前空白草稿提供单行追问建议。该功能受 `enableComposerPredictions` 控制，该配置为动态生效的 Volatile 布尔配置（`.volatile()`，默认 `false`），更新时实时生效并在关闭时立即中止活跃预测。客户端请求在功能关闭、缺少在线会话、会话不符、轮次运行中、序号过期、轮次失败、席位已退役或草稿非空时直接拒绝；独立的提前请求允许在同一在线轮次进行中启动。异步准入后、请求持久化检查点后、结果公开前及缓存复用前均重新核对生命周期、绑定、在线会话身份、已完成轮次和路由。后续窗口可复用仍有效的内存缓存而不再次推理；缓存不可用时，已有持久化请求记录会阻止自动重试不确定的调用。退役或删除绑定会中止活跃推理，即使建议被丢弃，已完成的模型用量仍保留。建议沿用任务的有效模型及推理强度，不切换其他模型，也不增加模型摘要调用。Host 上下文优先保留用户最初目标、最新请求、近期对话的部分摘录、本轮实际工具失败和返回结果以及当时可见的回复；长回复保留有界的开头与结尾。工具摘录仅作为不可信证据，不作为指令，也不代表任务成功。上下文排除运行环境、时钟注入、其他作用域及私密记忆。摘录先限量再拼接，上下文响应和完整序列化模型消息均遵守 `predictionContextMaxBytes`（默认 8192 字节），按 CJK 安全的 UTF-8 边界截断。桌面端通过可取消的 `streamComposerPrediction` Remote 流返回一个最终结果，不占用串行普通请求队列。开启功能后，普通根会话和团队协调员的实时回复首次出现至少 `predictionEarlyMinChars` 个字符（默认 30）且以完整句子结束时，就并发启动一次建议请求；若没有达到触发条件，则在符合条件的轮次完成后请求。队友席位和委派的子会话不会提前请求建议。轮次完成时可复用仍有效的提前结果，无需重复推理；正式任务的该次尝试失败或被放弃时会取消对应建议。提前生成的建议只求大致有用，用户可忽略。`predictionFirstTextTimeoutMs` 和 `predictionTimeoutMs` 均默认 0，关闭建议功能自身的两个超时限制。可配置正数分别限制首个非空白文字和整个请求的等待时长，仅有推理内容不算首个文字输出。草稿修改或离开会话会阻止提前结果显示；新轮次开始、关闭功能或服务销毁会中止提前请求，服务商传输层限制仍然生效。输出上限 `maxPredictionTokens`（默认 1024）包括服务商推理用量，可见建议仍为短句。若当前路由耗尽输出额度仍只有推理内容，可能不显示建议。只展示正常结束且通过校验的输出，超时不自动重试。分发前检查密钥模式，命中后不调用模型。

群聊轮次日志、阅读游标和辅助推理计费在档案写入租约下，使用串行、原子替换且同步到磁盘的 JSON 存储。加载时先校验全部记录，再公开内存状态；无效文件保持原样并阻止后续写入。只有持久化成功后，阅读游标才推进，计费记录才可见；重复的辅助调用标识不会重复计费。用量筛选从私密会话及团队历史运行实例解析会话标识，去重共享的会话，并排除各持久化会话从父会话继承的分叉前缀。


团队头像保留可选的本地选择标识，例如 `character:<preset>` 及历史 `icon:<preset>` 字符串；空字符串选择姓名缩写。默认头像由 Client 渲染。元数据与模型路由仅在持久化成功后生效；组合席位编辑会先校验模型，已退役席位不可编辑。协调者席位创建后，不允许更换团队协调者档案，以保留现有角色和会话身份。

`getTeamActivity` 仅读取团队当前在线协调者的成员、任务和交互；休眠团队不返回活动，读取不会恢复会话或触发模型调用。 显式执行团队初始化时，会为旧版空成员团队补建原协调者席位，并保留已有协调者会话。

空闲且尚未提交轮次的私密会话可通过 `clearConversationBinding` 解除智能体绑定；已有历史的会话需要新建普通对话。永久删除智能体与团队时校验确认窗口所用修订号，拒绝执行中的任务，并阻止恢复和标识复用。仍被保留团队引用的智能体不可删除。删除会擦除可复用配置与专属记忆，保留最少身份记录、已占用席位名称与会话日志。提示词组装和直接 Agent 执行均拒绝已删除身份，重启后仍有效。
