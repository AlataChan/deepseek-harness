# @deepseek-ai/dsh-experimental-client-ui-assistants

[English](README.md) | 中文

## 概述

`client-ui-assistants` 提供常驻智能体的浏览器界面组件：侧边栏智能体目录面板、首页英雄区卡片、带详情抽屉的专属会话头部，以及输入栏上方的角色专属建议提问。

目录独立加载智能体、团队和模型列表。团队或模型加载失败时显示错误，已保存的智能体卡片仍可显示。保存失败会保留输入内容并显示错误；首次智能体查询尚未完成时显示加载提示，不显示空目录。管理界面保留归档条目的查看入口。

## 交互行为

智能体与常驻团队的创建、编辑表单支持彩色首字母或内置预设图标。头像不请求外部图片，也不提供图片上传。团队视图支持成员编辑、成员模型覆盖与共享记忆；智能体详情支持私密记忆。已归档记忆可查看并恢复，删除记忆时会说明历史会话仍被保留。

常驻团队首次执行任务前也能打开只读成员面板。面板立即显示已保存成员，并仅在打开时观察已有在线活动；不会创建运行会话或调用模型。开始任务需要显式操作。加载、保存、路由及启动任务的失败会显示错误；保存失败保留草稿，方便修正。

浏览器入口先声明 `remote` 依赖并挂载生成的远程接口，再在依赖 `remote.assistants` 的子作用域中注册界面。输入建议从 Host 获取已完成轮次上下文，并通过原生远程信号传递取消请求。输入文字、切换会话、开始执行或卸载时丢弃未完成建议；输入后清空不会为同一轮次重新请求建议。采用建议只将可编辑文本插入输入栏，不提交提示词。

## 模型体验

间接通过会话级模型路由控制与角色专属建议提问的草稿插入影响交互。

#### KV 缓存影响

建议提问通过草稿插入由用户确认后提交，在正式提交前不改变缓存前缀。
