# @deepseek-ai/dsh-experimental-client-ui-assistants

[English](README.md) | 中文

## 概述

`client-ui-assistants` 提供常驻智能体的浏览器界面组件：侧边栏智能体目录面板、输入框上方的统一身份选择器、带详情抽屉的专属会话头部，以及输入栏上方的角色专属建议提问。

团队或模型加载失败时，目录保留已保存的智能体卡片；保存失败保留草稿，管理界面支持查看归档条目。原协调员不可选时仍可修改团队资料；更换协调员必须选择可用智能体。

## 交互行为

目录独立加载智能体、团队和模型列表。团队或模型加载失败时显示错误，已保存的智能体卡片仍可显示。保存失败会保留输入内容并显示错误；首次智能体查询尚未完成时显示加载提示，不显示空目录。管理界面保留归档条目的查看入口。 原协调员已归档或不在可选智能体列表时，仍可修改团队资料；改选协调员时必须选择可用智能体。

智能体与工作区的选择在打开对话前汇合到同一个已绑定会话。先选智能体时，先显示工作区选择器，不创建会话；先选工作区时，复用该工作区当前未绑定智能体的空白会话。已有聊天记录或已绑定其他智能体的会话，会在同一工作区另开会话。取消选择器不创建会话，绑定失败不跳转，后续导航会阻止尚未完成的跳转。发送前，输入栏根据 Host 确认的会话绑定显示智能体头像和名称；普通会话不显示智能体标识。

智能体与常驻团队的创建、编辑表单提供五张已确认的生成头像：海边小伙伴（小绿鲸、米白海豹、杏桃海豹）及可选的软萌机器人（鼠尾草、珊瑚）。旧角色选择自动映射到这套头像，不改写已保存的智能体。图片以内嵌 WebP 资源提供，可离线显示。未设置头像时默认使用海边小鲸鱼；明确选择的姓名缩写和已保存的历史图标继续保留。切换系列或角色沿用现有头像保存操作。头像不请求外部图片，也不提供图片上传。团队表单限制在窗口内，可用高度不足时在内部滚动。团队视图支持成员编辑、成员模型覆盖与共享记忆；智能体详情支持私密记忆。已归档记忆可查看并恢复，删除记忆时会说明历史会话仍被保留。

常驻团队首次执行任务前也能打开只读成员面板。面板立即显示已保存成员，并仅在打开时观察已有在线活动；不会创建运行会话或调用模型。开始任务需要显式操作。加载、保存、路由及启动任务的失败会显示错误；保存失败保留草稿，方便修正。

浏览器入口先声明 `remote` 依赖并挂载生成的远程接口，再在依赖 `remote.assistants` 的子作用域中注册界面。输入框建议注册于 `conversation.input.overlay`（order 10），仅在前台观察到执行中到空闲的转换后从 Host 获取已完成轮次上下文，并通过只返回一个结果的 `streamComposerPrediction` Remote 流及其原生取消信号接收建议，避免占用桌面的串行普通请求队列；打开历史会话不会发起推理。透明灰色建议随常驻编辑器的位置和字体布局，显示期间暂时隐藏原占位文字，并在窗口缩放和卸载时恢复。输入文字、开始输入法组字、更改会话模型选择（包括推理强度）、切换会话、开始执行或卸载时，立即取消未完成请求并丢弃已显示建议；取消组字后输入框仍为空，或把模型切换回来，都不会为同一已完成轮次重新请求建议。在空白输入框中，按 Tab 键或点击鼠标可通过常驻 Lexical 编辑器插入可编辑文本采纳建议而绝不触发表单提交，并对 Shift+Tab、输入法组字中以及打开的弹出菜单保持安全忽略。编辑器因修订冲突拒绝插入时保留建议，允许重试。关闭开关会立即取消订阅并拒绝延迟返回的结果，快速关闭再开启也不会恢复旧结果。通用设置提供基于 Volatile 配置表单的实时选用开关条目（`settings.general.item`，order 85）。

身份栏提供取消空白会话选择的操作；已有历史时，在同一工作区新建普通对话。执行中的会话禁用此操作。管理页可显示已归档智能体与团队；永久删除需二次确认，并说明历史聊天与工作区文件保留。删除失败保留条目与确认窗口，对团队引用、执行中任务和修订冲突给出具体提示。操作结果提示由应用外层持有，关闭管理页后仍可显示。

选择器默认显示与输入框相连的简洁身份栏。点击“展开头像”显示智能体与团队分组头像，点击“收起头像”恢复简洁模式。展示偏好仅保存在浏览器本地，并在已挂载选择器及窗口间同步，不更改 Host 绑定或创建会话。选择智能体沿用工作区绑定流程；选择团队直接打开已保存的团队视图，不初始化运行实例或调用模型。当前身份由 Host 确认，团队身份优先于协调员智能体。卸载本插件后，原机构团队首页卡片恢复显示。选择菜单沿用共享的门户菜单，窄窗口中头像分组纵向排列。

<a id="model-experience"></a>
## 模型体验

间接通过会话级模型路由控制与角色专属建议提问的草稿插入影响交互。

#### KV 缓存影响

建议提问通过草稿插入由用户确认后提交，在正式提交前不改变缓存前缀。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 经评估，在不修改上游 `ui-model-selection` 的前提下遮蔽会话模型槽位不可行；会话级模型选择由头部操作与详情抽屉承载。
