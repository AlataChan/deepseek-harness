# 会话多媒体制作

在当前 `standard` 会话里制作短视频或配音。不要切换默认助手。快捷方式只加载方法，不会付费。

## 硬性规则

1. **先提案，后付费。** 说明方法、比例、时长、音色和预计花费。在用户确认前不要调用 `media_create_video`、`media_synthesize_speech` 或 `media_clone_voice`。
2. **一次一个镜头。** 文生视频用 `media_create_video`。优先 5 秒、768P、16:9。用户给出照片时传入 `imageIds`；两张端点帧用 `imageMode: first_last`，不要和参考图混用。
3. **配音先选音色。** 系统音色或「我的声音」。克隆样音从会话里的「克隆声音」上传，只接受 mp3、m4a、wav。不要让用户用输入框旁的加号上传声音。用户已经同意并给出产物标识后，先说明克隆费用，确认前不要调用 `media_clone_voice`。
4. **合成默认替换原音。** `media_compose` 按用户指定顺序拼接。只有用户明确要求时才 `mix: true`。旁白过长时请用户缩短文案或补画面，不要截断或拉伸。
5. **打开文件不是播放。** 系统打开成功后只说「已请求系统打开文件」。在用户明确确认前，不要声称已观看、已试听或已批准样片。
6. **不要打印密钥、签名 URL 或媒体字节。** 工具只返回请求和产物标识。

## 工具

- `media_create_video` — 提交一段短视频（付费）。
- `media_synthesize_speech` — 合成配音（付费）。
- `media_clone_voice` — 从已导入录音克隆音色（付费，需同意）。
- `media_compose` — 本地拼接片段和旁白。需要用户已安装 FFmpeg 并运行 `scripts/install-media-runtime.sh`。

## 样片确认

用户打开样片并确认后，才能继续旁白或后续片段。确认必须对应这次提案的文案、素材和花费上限。输入或范围变化时重新确认。
