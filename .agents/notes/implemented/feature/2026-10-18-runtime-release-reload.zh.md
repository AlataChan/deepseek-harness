# Agent Note：拒绝其他 Host 运行时发布的客户端模块

状态：已实现

[English](2026-10-18-runtime-release-reload.md) | 中文

## 决策

图携带 Host 运行时发布身份，与插件修订和 Tauri 外壳版本分开。共享桌面构建生成器读取 CLI 运行时版本和完整源码提交。完整 Git 构建通过 `DSH_CLIENT_RELEASE_VERSION` 与 `DSH_CLIENT_RELEASE_COMMIT` 提供身份；现有短 `DSH_CLIENT_COMMIT_HASH` 仍作为显示元数据。Node 和浏览器产物嵌入发布字段，桌面产物元数据使用同一生成器。

Tauri 引导保留安装清单与伴随进程的运行时版本检查，并在缓存或加载工厂之前比较图版本。本地缓存 URL 改写保留图发布身份。启动后，页面在解析或应用替换图之前先读取发布身份。其他发布暂停插件更新并提示重新加载；关闭提示不会接纳该发布。现有页面及其状态继续运行。

没有发布身份的旧图可与同样缺少身份的图协调。身份缺失与存在之间的任意方向切换都需要重新加载。源码和局部构建可缺少提交号；打包要求完整的规范身份。同一发布内的图修订仍可正常更新。

## 影响

发布不一致时，无法在运行中的页面下热替换共享代码。用户可推迟重新加载并保留当前页面。推迟不迁移会话、不删除设置，也不更新应用文件。此流程不依赖账号服务、更新服务器或强制升级策略。
